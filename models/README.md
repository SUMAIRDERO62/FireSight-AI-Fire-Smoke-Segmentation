# Model checkpoints

Store generated checkpoints under `checkpoints/`. Checkpoints are ignored by
Git; document reproducible training commands and artifact locations here.

Supported adapters:

- U-Net: `checkpoints/unet.pt`
- YOLO11-seg: `checkpoints/yolo11-seg.pt`

Do not commit checkpoints or generated model artifacts. No checkpoints are
included in the Phase 00 repository.
