# Methodology

1. Select and document a Kaggle segmentation dataset.
2. Inspect and validate image-mask pairs.
3. Prepare fire and smoke segmentation annotations consistently.
4. Train U-Net and YOLO11-seg on the same dataset splits.
5. Evaluate segmentation quality with reproducible, reported metrics.
6. Package validated checkpoints behind the shared segmentation interface.
7. Compare both models through the image-upload application.

Model training, dataset acquisition, fake masks, and reported results are
outside the Phase 00 audit scope.
